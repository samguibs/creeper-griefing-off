# Creeper Griefing Off

A Minecraft mod that prevents creepers from destroying blocks while preserving explosion damage and knockback.

## Supported Versions

### Fabric / NeoForge

* Minecraft 26.1.x (26.1, 26.1.1, 26.1.2)
* Minecraft 26.2
* Minecraft 26.3

## Installation

Install the version that matches your Minecraft version and mod loader, then place the `.jar` file in your `mods` folder.

> For Fabric, the Fabric API is also required.
